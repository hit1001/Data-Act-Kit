# R5 — interface review checklist (Art. 4(4), Art. 6(2)(a))

Reviewed against the portal (`packages/server/public/`) before each release. A reviewer who did not
write the change checks every item and signs off below.

- [ ] Grant, decline and revoke controls have the same size, style and position weight; none is pre-selected.
- [ ] Revoking a grant is one action from the grants list.
- [ ] Declining an agreement is as visible as accepting it.
- [ ] No pre-ticked boxes, countdown pressure, or wording that discourages exercising data rights.
- [ ] Data points withheld from an export are listed with the reason, not hidden.
- [ ] The customer is told sharing is free of charge for them.
